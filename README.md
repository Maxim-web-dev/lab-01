# toolkit

Калькулятор и конвертер величин через консоль

## Установка

```bash
pip install -e .
```

## Использование

```bash
python -m toolkit calc "2+3*4"
python -m toolkit convert 1000 --from mm --to m
python -m toolkit --help
```

## Калькулятор

Поддерживает +, -, *, /, дробные числа, унарный плюс и минус. Умножение и деление считаются раньше сложения и вычитания. eval и exec не используются — разбор идёт через tokenizer, validation и calculations.

Например, -2 * -3 — оба минуса унарные, поэтому получается (-2) * (-3) = 6.

## Конвертер

Длина: mm, cm, m, km. Масса: g, kg. Температура: c, f, k. Между разными группами конвертировать нельзя, регистр единиц не важен.

## Ошибки

При ошибке — сообщение в stderr и код 2. При успехе — код 0.
